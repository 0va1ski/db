## 📦 Быстрый старт
Прежде чем запускать программы, создайте свою копию репозитория и скачайте её на компьютер.<br>
Подробная пошаговая инструкция (форк, клонирование, настройка Git, отправка изменений) находится в
[общем README](../README.md).
 
Коротко:
```bash
git clone https://github.com/ВАШ_ЛОГИН/isit.git
cd isit/laba5
```
Вместо `ВАШ_ЛОГИН` подставьте логин своего аккаунта на GitHub. Работайте в **своём** репозитории, а не в оригинале.
 
### Что нужно знать
- теоретический минимум из раздела «Теория»;<br>
- примерное представление о решении.
### Структура папки
| Папка | Содержимое |
|---|---|
| `a/` | решения задания а: `a1.cpp`, `a2.cpp` |
| `b/` | решения задания б: `b1.cpp`, `b2.cpp` |
| `imgs/` | иллюстрации к теории |
| `my/` | **ваши** решения (создайте эту папку сами) |

Свои решения кладите в папку `my/` и не правьте чужие файлы, тогда обновления из оригинала не вызовут конфликтов.
 
### Сборка и запуск
Готовых `.exe` в репозитории нет, программы нужно **собрать**. Формат команды:
```bash
g++ -std=c++17 исходный_файл.cpp -o имя_программы
```
| Задание | Исходник | Сборка | Запуск (Windows) | Запуск (Linux, macOS) |
|---|---|---|---|---|
| а, способ 1 | `a/a1.cpp` | `g++ -std=c++17 a/a1.cpp -o a1` | `.\a1` | `./a1` |
| а, способ 2 | `a/a2.cpp` | `g++ -std=c++17 a/a2.cpp -o a2` | `.\a2` | `./a2` |
| б, способ 1 | `b/b1.cpp` | `g++ -std=c++17 b/b1.cpp -o b1` | `.\b1` | `./b1` |
| б, способ 2 | `b/b2.cpp` | `g++ -std=c++17 b/b2.cpp -o b2` | `.\b2` | `./b2` |

Команды выполняйте из папки `laba5`. Если сборка прошла успешно, команда ничего не выведет, а рядом появится готовый файл.<br> 
Числа генерируются случайно, поэтому при каждом запуске результат будет разный.
