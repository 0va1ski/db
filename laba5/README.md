## 📦 Быстрый старт
### Требования
Знать теоретический минимум.<br>
Иметь примерное представление о решении.<br>
У вас должен быть установлен [VS Code](https://code.visualstudio.com/) или [Clion](https://www.jetbrains.com/de-de/clion/) или [DEV C++](https://www.embarcadero.com/free-tools/dev-cpp).
### Установка и запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Перейдите в папку проекта:
   ```bash
   cd project-name
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите проект:
   ```bash
   npm run dev
   ```
